# Changelog

## 0.2.0 — End-to-end inventory decision study

- Replaced Stockpyl execution with a from-scratch daily Python simulator.
- Added multiple SKUs, configurable warehouse/store tables and per-order lead times.
- Added service-aware candidate selection, chronological evaluation and daily accounting.
- Added a portable HTML report, paired uncertainty plots and raw trial outputs.
- Expanded executable checks to 13 tests and documented each business question.

## 0.1.0 — Initial Stockpyl prototype

Single-SKU three-node model, fixed scenario lead times, joint enumeration and
synthetic paired simulation evaluation. Preserved in Git history.
